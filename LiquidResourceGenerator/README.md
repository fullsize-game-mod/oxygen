# 液体资源生成器

参考固体资源生成器，为《缺氧》新增一座仅靠电力生成指定液体元素、通过液体管道输出的建筑。可与仓库中的其他 Mod 分别安装、启用。

当前版本：**1.0.0**。

| 项目 | 行为 |
| --- | --- |
| 建造位置 | 实用（Utilities）菜单，无需额外研究 |
| 占地与外观 | 1×2 格，建在地面上，复用原版氧气扩散器动画 |
| 建造成本 | 200 kg 金属矿石或精炼金属，30 秒 |
| 工作耗电 | 120 W，不能生产时待机 |
| 生成速度 | 0～100 kg/s，支持一位小数；默认 1 kg/s，实际输出受管道容量限制 |
| 更新频率 | 每 200 ms 按设置速度和剩余缓冲容量生成 |
| 输入 | 无需原料或复制人操作 |
| 资源选择 | 原版单选侧栏，列出当前已加载、满足生成条件的液体元素，无需事先发现或拥有 |
| 设置保存 | 每台建筑独立保存资源与速度，支持复制建筑设置 |
| 自动化控制 | 上方格为输入口：绿灯允许生产，红灯停产；未接线时允许生产 |
| 输出 | 底部格为液体管道出口，由原版液体排放器接入管网 |
| 内部缓冲 | 最多 20 kg，密封保存待排液体；未接管道、出口堵塞或缓冲满时停止生成 |
| 产物温度 | 尽量为 20°C，限制在凝固点以上和沸点以下各留 1 K 的范围内，最低 1 K |
| 停机条件 | 断电、自动化红灯、手动禁用、无效资源、零速度或输出不可用；不受淹没或过热限制 |

## 安装与使用

1. 解压 [LiquidResourceGenerator.zip](../dist/LiquidResourceGenerator.zip)，将整个 `LiquidResourceGenerator` 文件夹放入游戏的 `mods/Local/` 目录。各系统路径见[仓库安装说明](../README.md#安装)。
2. 在游戏 Mod 列表启用“液体资源生成器”，按提示重启。
3. 在“实用”菜单建造生成器，连接电线与底部液体管道出口，并为下游提供可接收液体的设备或排液口。
4. 在资源侧栏选择液体，使用“生成速度”滑块或数字输入框调整速度。未发现或从未持有过的有效液体也可选择。
5. 需要自动化时，将自动化线接至上方输入口。绿灯生产，红灯停止生成；未接线时可正常生产。

安装后的目录应为：

```text
mods/Local/LiquidResourceGenerator/
├── LiquidResourceGenerator.dll
├── mod.yaml
└── mod_info.yaml
```

## 管道与资源边界

- **仅通过液体管道输出。**不往地面排液，也不生成瓶装物品。调速范围沿用固体版，设置超过管道吞吐能力时，实际生产与输出会受限。
- **不删除已有液体。**切换资源只影响后续生成；已生成的液体保留在缓冲或管道中，由原版排放器继续排出。切换后管道中可能先后出现不同种类的液体，下游设备应能接收它们。
- **停产与排空分开。**速度设为 0、自动化红灯、断电或手动禁用会停止生成；缓冲内已生成的液体仍可由原版排放器排出。拔掉管道或堵塞出口时保留缓冲，恢复连接与流通后继续工作。
- **无需预先发现资源。**菜单从当前加载的液态元素动态构建，不修改原版共享发现记录，不改变其他建筑的筛选规则。其他 Mod 添加的液体满足相同条件时也可使用。
- **只允许可安全生成的液态元素。**元素必须未禁用、标签与元素一致、具有物质数据及可用预制体，且相变温度为有限值、能留出上述 1 K 余量。食物、种子、蛋、装备、固体和气体不会进入列表。不存在或不再有效的存档选择会使建筑待机。
- **温度按元素调整。**水等常温液体尽量以 20°C 生成；液氧等低温液体在其沸点以下生成，熔融金属在其凝固点以上生成。进入管道后仍遵循游戏换热与相变规则，需选用合适的管道和下游设备。
- **DLC 与版本影响实际列表。**不解锁未加载的 DLC 元素，也不强制启用禁用元素。最终以当前游戏资源菜单为准。

已有存档可建造此建筑。包含本建筑的存档应保持 Mod 启用；卸载前先排空、拆除新增建筑。

## 编译与检查

与仓库其他 Mod 使用相同的 .NET SDK、Harmony 2.4.2 和游戏程序集路径配置，在仓库根目录执行：

```sh
dotnet build LiquidResourceGenerator/LiquidResourceGenerator.csproj -c Release "-p:GameManagedPath=/absolute/path/to/Managed"
dotnet run --project tests/LiquidGeneration/LiquidGeneration.csproj -c Release
```

构建自动更新 `dist/LiquidResourceGenerator/`，发布时需将整个文件夹重新压缩为 ZIP。安装包只包含本 Mod 的 DLL 与两个 YAML 文件，不附带游戏、Unity 或 Harmony 程序集。

**验证范围：**使用 OniStubs 2.0.0 与 Unity 编译引用构建。独立检查直接执行生产组件和资源列表补丁，覆盖断电、管道断开与堵塞、恢复生产、缓冲容量、资源切换保留已有液体、0～100 kg/s 调速、复制与保存字段、异常输入、常温/低温/高温液体温度、未发现元素、无选择项、分类及原版共享数据隔离。

这些检查使用替身隔离游戏边界，不执行真实 Harmony 注入、管道调度、UI 或存档序列化。**尚未完成游戏内验收**：需确认建筑菜单与出口预览、资源侧栏与滑块、实际管道吞吐与堵塞恢复、自动化、电力、复制设置与保存重载，以及液氧、熔融金属等资源的温度与相变行为。声明的最低版本为 718946，API 版本为 2；公开编译引用早于此版本，不能证明当前游戏 API 完全兼容。
