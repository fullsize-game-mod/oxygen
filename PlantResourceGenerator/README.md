# 植物收获物生成器

为《缺氧》新增一座仅靠电力生成植物收获物的建筑。沿用固体资源生成器的建筑外观、操作方式、速度范围和自动化控制，可以独立安装，也可以与仓库中的其他生成器一起启用。

当前版本：**1.0.0**。

| 项目 | 行为 |
| --- | --- |
| 建造位置 | 实用（Utilities）菜单，无需额外研究 |
| 占地与外观 | 1×2 格，建在地面上，复用原版氧气扩散器动画 |
| 建造成本 | 200 kg 金属矿石或精炼金属，30 秒 |
| 工作耗电 | 120 W；未选择有效资源、速度为 0 或自动化红灯时待机 |
| 生成速度 | 0～100 kg/s，默认 1 kg/s，滑块或数字输入，支持一位小数 |
| 输入 | 无需种植、原料、管道或复制人操作 |
| 资源选择 | 原版单选侧栏，列出已加载作物的可拾取收获物，无需事先发现或拥有 |
| 设置 | 每台建筑独立保存资源和速度，支持复制建筑设置 |
| 自动化控制 | 上方格输入口：绿灯生产，红灯停机；未接线时允许生产 |
| 输出 | 每 200 ms 按所设速度将收获物掉落在建筑脚下 |
| 产物温度 | 通常为 20°C；固体元素产物会限制在熔点以下，最低 1 K |
| 停机条件 | 断电、自动化红灯、手动禁用等原版运行条件；不受淹没或过热限制 |

## 收获物范围

列表从游戏已加载植物预制体的 `Crop.cropVal` 收获配置中读取，不使用写死的白名单，也不依赖食物加工配方。因此同时支持食用、烹饪原料和非食用收获物；树枝等带有 `Crop` 的子预制体也会扫描，同种产物只出现一次。

典型收获物包括植物果实、蘑菇、芦苇纤维、木材、香水百合花，以及冰霜小麦谷粒、释盐藤豆类等。**这些是收获配置类型的示例，具体列表以当前游戏已加载且通过检查的预制体为准，不是逐项游戏内实测名单。**

- 谷粒、豆类等本身就是作物收获物的种子会保留。普通繁殖种子若仅由 `SeedProducer` 掉落，不会自动加入列表。
- 不生成植物本体；肉、蛋、熟食、建筑等不会因其属于食物或物品而加入列表，只有被作物收获配置明确指定的产物才会进入检查。
- 收获数量须大于 0，且产物须有匹配的可拾取预制体、有效的单位质量和 `PrimaryElement`。缺失的 DLC 产物、无效预制体和空分类会排除。
- 固体元素收获物也可生成；液体、气体元素不支持此掉落输出方式。通过其他专用逻辑持续分泌液体、气体或掉落物的植物，若没有对应的 `Crop` 收获配置，不会自动收录。
- DLC 和其他 Mod 新增的作物只要已加载且满足条件即可出现，不会解锁未加载的 DLC 内容。刷新列表与生产时会重新读取配置；原产物被移除后，已有选择会安全停机。
- 产量按**质量**计算，不按植物一次收获数量或物品单位数计算。例如 2.5 kg/s 每 200 ms 产生 0.5 kg，谷粒和豆类会按自身单位质量换算数量。
- 直接实例化产物自身预制体，保留食用、腐败、种植和工业用途。生成后的温度、物相及其他行为仍由游戏处理。

无选择项单独使用原版保留的 `Void` 分类。与固体生成器重叠的元素使用同一材料分类，与食物生成器重叠的食物物品使用 `CookingIngredient` 分类，以避免共享侧栏在反复切换时缓存同一资源的重复行。建议同时使用仓库中的最新版生成器。

## 安装与使用

1. 解压 [PlantResourceGenerator.zip](../dist/PlantResourceGenerator.zip)。
2. 将整个 `PlantResourceGenerator` 文件夹放入游戏的 `mods/Local/` 目录，详见[仓库安装说明](../README.md#安装)。
3. 启用“植物收获物生成器”，按游戏提示重启。
4. 在“实用”菜单建造生成器并连接电线，在侧栏选择一种收获物。
5. 设置生成速度；设为 0 暂停生产。需要自动启停时，将自动化线接到建筑上方输入口。

安装后的目录应为：

```text
mods/Local/PlantResourceGenerator/
├── PlantResourceGenerator.dll
├── mod.yaml
└── mod_info.yaml
```

已有存档可建造此建筑。包含此建筑的存档应保持本 Mod 启用；卸载前先拆除新增建筑。

## 编译与验证

与其他生成器使用相同的 .NET SDK、Harmony 2.4.2 和游戏程序集路径配置，在仓库根目录执行：

```sh
dotnet build PlantResourceGenerator/PlantResourceGenerator.csproj -c Release "-p:GameManagedPath=/absolute/path/to/Managed"
dotnet run --project tests/PlantGeneration/PlantGeneration.csproj -c Release
dotnet run --project tests/ResourceSidebar/ResourceSidebar.csproj -c Release
```

构建后自动更新 `dist/PlantResourceGenerator/`；发布时需重新压缩整个文件夹为 ZIP，游戏和 Unity 程序集不随 Mod 分发。
