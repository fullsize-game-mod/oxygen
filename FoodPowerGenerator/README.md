# 食物发电器

独立 Mod，不依赖食物原料生成器。启用后可在建造菜单的「电力」分类找到，无需研究。

1. 建造食物发电器，将电力输出口接入有负载或电池的电路。
2. 在建筑侧栏勾选愿意用于发电的食物，复制人会搬运对应物品。默认未选燃料，储存上限为 20 kg。
3. 接入有效电路且有食物时自动发电。需要按需启停时，可接智能电池的自动化输出：红灯停止消耗，绿灯允许发电，未接自动化线时默认允许发电。

| 参数 | 数值 |
| --- | --- |
| 热量换算 | 1 kcal → 10 J |
| 额定功率 | 600 W（每秒消耗约 60 kcal） |
| 例：800 kcal 泥糕 | 共生成约 8 kJ，满功率约 13.3 秒 |

换算为游戏平衡设定，不是物理热量的焦耳换算。发电按食物实际被消耗的份数结算；余量不足一个生产周期时只输出对应电量。同一种燃料不要求固定质量。只使用有正热量的可食用物品，不能用仅作为配方原料的非食用物品、活物或腐烂物代替；库存不冷藏。

发电量是发电机输出，不保证电池实际收到同等电量：电路可能用不完，建议用智能电池自动化避免浪费。

版本 1.0.0。构建和安装见[仓库总览](../README.md)。游戏内尚未验收；建议先备份存档，并检查侧栏供料、发电与自动化启停。
