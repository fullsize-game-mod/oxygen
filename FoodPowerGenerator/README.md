# 食物发电器

独立 Mod，不依赖食物原料生成器。启用后可在建造菜单的「电力」分类找到，无需研究。

1. 建造食物发电器，将电力输出口接入有负载或电池的电路。
2. 腐烂物由复制人自动搬运，不用在筛选栏勾选；库存上限为 5 kg。可用建筑菜单的原版手动运送开关暂停补货，暂停前已存入的腐烂物仍可发电。
3. 如需用仍可食用的食物发电，在侧栏另外勾选种类。默认不收食物，食物库存上限为 20 kg。
4. 接入有效电路且有燃料时自动发电，先用腐烂物。接智能电池可按需启停：自动化红灯停止消耗，绿灯或未接自动化线时允许发电。

| 参数 | 数值 |
| --- | --- |
| 热量换算 | 1 kcal → 10 J |
| 腐烂物换算 | 1 kg → 600 J |
| 额定功率 | 两种燃料共用 600 W 上限 |
| 例：800 kcal 泥糕 | 共生成约 8 kJ，满功率约 13.3 秒 |

腐烂物已经没有食物热量，因此按质量换算；1 kg 可满功率运行约 1 秒。只认游戏里的「腐烂物」，不是所有堆肥物；污染土和非食用原料不能发电。仍可食用的食物按实际消耗的热量换算，库存不冷藏。余量不足一个生产周期时只发出剩余燃料对应的电量。

发电量是发电机输出，不保证电池实际收到同等电量：电路可能用不完，建议用智能电池自动化避免浪费。

版本 1.1.0。构建和安装见[仓库总览](../README.md)。游戏内尚未验收；建议先备份存档，并检查两种燃料的搬运、发电与自动化启停。
